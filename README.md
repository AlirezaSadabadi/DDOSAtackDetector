# 🛡️ DDoS Attack Detection Using Expert Systems

This project implements a Distributed Denial of Service (DDoS) attack detection system using **Expert Systems**, developed as part of my master's thesis.

It uses a rule-based expert system that analyzes traffic symptoms and historical behavior to detect DDoS attacks. The system is built using **Visual Studio .NET** and **Entity Framework**, making it flexible and database-independent.

---

## 📚 Abstract

We aimed to detect DDoS attacks by building an expert system that utilizes known **attack symptoms** and **historical data**. Due to the increasing complexity of DDoS attack patterns and algorithms, traditional static methods are insufficient. Expert systems provide adaptability and learning capabilities to evolve detection strategies over time.

The system was implemented in **Visual Studio .NET**, and its performance was compared with simulation tools such as **Netica** to validate accuracy and effectiveness.

---

## 🧰 Features

- ✅ Rule-based detection using expert systems
- 🔄 Simulation of various DDoS attack scenarios
- 🛠️ Built with Entity Framework for database flexibility
- 📊 Comparison with Netica for simulation and validation

## 🚀 Getting Started

### Prerequisites

* [.NET Framework](https://dotnet.microsoft.com/) (recommended version: 4.7+)
* Visual Studio (2019 or later)
* SQL Server or any relational DB (via Entity Framework)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/yourusername/ddos-expert-system.git
   cd ddos-expert-system
   ```

2. **Open the project in Visual Studio**

3. **Configure your database connection** in `web.config`.

4. **Build and run** the solution.
